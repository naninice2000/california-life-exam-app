About question repetition and exam realism

Levels preserve the original question banks. Topics repeat across levels, and some questions are variations of the same core concept. In particular, the advanced bank contains 750 distinct prompts but not 750 entirely independent concepts. These are unofficial practice materials, not actual California PSI exam questions.

How saved progress works

Each level saves answers separately in your browser’s localStorage. Refreshing the page does not normally reset progress. Progress is browser- and site-specific: switching from local files to GitHub Pages or to another device does not automatically migrate existing answers. Avoid clearing site data if you want to retain progress.
